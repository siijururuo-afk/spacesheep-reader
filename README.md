# 슝 · 聊天存档

白底黑字的韩中对照聊天阅读网站。按韩国时间（UTC+9）从旧到新排列，收录 1,720 条可访问消息。

## 阅读

- 日期目录、全文搜索、只看图片与链接。
- 中文 / 中韩对照 / 韩文三种模式，字号调整。
- 每条消息有独立锚点；保存本机阅读位置。
- 图片本地存档，点击放大；保留原站链接与可嵌入的视频。
- 下载完整中韩对照 Markdown。

## 本地使用

直接打开 `index.html`，或在该目录运行 `python -m http.server 8000`。无需安装依赖，没有服务器端代码、跟踪器或密钥。

## GitHub Pages

仓库 Settings → Pages → Build and deployment → Source 选择 **Deploy from a branch**，Branch 选择 **main / (root)**，保存。部署完成后，地址通常为 `https://siijururuo-afk.github.io/spacesheep-reader/`。
